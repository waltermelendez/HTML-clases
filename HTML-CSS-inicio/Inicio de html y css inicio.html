Html y Css inicio

Este es el "Inicio del doucmento de inicio de html y css."

Este docuemto contiene las cosas que todo recien llegado a ver html y css debe saber para poder crear una pagina web, de una forma decente sin saber como programar en JavaScript.

Tipos de subtitulos

Hay varios tipos de subtitulos, estan desde el h1 hasta el h6. Estos tipos de letas se usan para poder tener una base en el tamanio de las letras en una pagina web.

Tipos de "h"

Existen varios tipos de letras, estos son:

  • h1: Es el texto mas grande de las "h", frecuente mente se usa como titulo.
  • h2: Este tipo de texto se usa para poder hacer subtitiulos de un tema.
  • h3: Su posible uso seria como texto normal.
  • Los textos h4, h5, h6 son demasiado pequenios para poder ser usados en un pagina web.
